# 온보딩 UX 설계 - Day 3.5 핸드오프

## 0. 확정 정책

- 흐름: 위저드, 1질문 1스텝
- "해당 없음": 배타 선택
  - "해당 없음" 선택 시 같은 질문의 다른 항목은 자동 해제
  - 다른 항목 선택 시 "해당 없음"은 자동 해제
- 다중선택 최소 개수: 1개 이상 강제
  - "해당 없음"이 있는 질문은 "해당 없음" 1개 선택도 유효
- 새로고침 후 복원: 하지 않음
  - zustand 메모리 draft만 유지

## 3. 컴포넌트 분해와 Day 4 shadcn 매핑

| 컴포넌트 | 역할 | shadcn 후보 |
|---|---|---|

## 4. 인터랙션

- 선택 시각 피드백: 미선택은 회색 보더, 선택은 에메랄드 배경 + 흰 글자 + 체크마크
- 이전 버튼: 답 유지, 첫 스텝에서는 비활성화
- 다음 버튼 활성 조건:
  - 단일선택: 1개 선택
  - 다중선택: 1개 이상 선택
- 마지막 스텝 Q8의 다음 버튼 라벨: 완료
- 완료 시:
  - zustand draft 답변을 묶어 백엔드 mutation 1회 호출
  - 성공 시 `/lobby` 이동
  - 토스트: "프로필이 저장되었어요! 맞춤 시나리오 추천에 반영됩니다!"
- 로딩:
  - 다음 버튼은 로딩 없음, 스텝 간 이동은 client only
  - 완료 버튼만 mutation 로딩 표시

## 5. 카피

- 페이지 메인 카피: 맞춤 피싱 훈련을 준비해볼게요
- 페이지 보조 설명: 몇 가지 생활 패턴을 알려주시면 더 현실적인 시나리오를 추천합니다.
- Q1 직업: 직업군에 따라 자주 노출되는 사기 유형이 달라져요.
- Q2 연령대: 연령대별로 익숙한 채널과 위험 신호를 다르게 안내할게요.
- Q3 성별: 시나리오 통계와 표현을 더 균형 있게 조정하는 데 사용돼요.
- Q4 소비활동: 자주 이용하는 소비 영역을 바탕으로 더 현실적인 상황을 추천해요.
- Q5 소통채널: 평소 자주 사용하는 연락 수단을 모두 골라주세요.
- Q6 온라인활동: 최근 접점이 있었던 온라인 활동을 기준으로 위험 상황을 맞춤화해요.
- Q7 금융거래: 주로 이용하는 금융 거래 방식을 모두 골라주세요.
- Q8 가족구성: 함께 생활하는 가족이 있나요?

## 6. 접근성 / 모바일

- 단일선택: `role="radiogroup"` + `role="radio"` + `aria-checked`
- 다중선택: `role="group"` + 각 옵션은 `button` + `aria-pressed`
- 모바일 1열, 태블릿 2열, 데스크톱 3열
- 긴 라벨은 축약해 칩 안에서 안정적으로 보이도록 정리

## 7. 구현 메모

- 표의 Q5 옵션 수가 6개로 확정되어 있어 연락 수단에는 "해당 없음"을 넣지 않음
- Q4, Q7의 "해당 없음" 저장을 위해 백엔드 enum에 `NONE("none")` 추가
- 온보딩 API JSON 요청 필드는 확정안에 맞춰 snake_case 사용
